# Absolute Value of an Integer

## Problem Statement

Write a Java program that accepts an integer from the user and prints its absolute value.

The absolute value of a number is its distance from zero, so it is never negative.

## Sample Input and Output

**Example 1 — Negative integer**

Input:
```text
Enter an Integer:
-15
```

Output:
```text
15
15
```

**Example 2 — Positive integer**

Input:
```text
Enter an Integer:
8
```

Output:
```text
8
8
```

**Example 3 — Zero**

Input:
```text
Enter an Integer:
0
```

Output:
```text
0
0
```

## Concepts Practised

- Java variables and integer data types
- User input using `Scanner`
- `if` and `if-else` statements
- Comparison operators
- Unary negation
- Updating variable values

## Learning Objective

Understand how conditional statements can be used to handle negative, positive, and zero values, and compare two approaches to calculating an absolute value.

## Complexity Analysis

- Time complexity: O(1)
- Auxiliary space complexity: O(1)
